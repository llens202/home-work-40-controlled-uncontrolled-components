# Controlled & Uncontrolled Components

Навчальний React-проєкт, у якому продемонстровано роботу з контрольованими (Controlled) та неконтрольованими (Uncontrolled) компонентами, а також виконання запиту до сервера за допомогою `useEffect`.

## Опис проєкту

У проєкті реалізовано дві форми:

* **ControlledForm** — контрольована форма, у якій значення полів зберігаються та контролюються через `useState`.
* **UncontrolledForm** — неконтрольована форма, у якій значення поля отримується через `useRef` без використання `useState` для самого input.

Також у `UncontrolledForm` реалізовано отримання даних користувача із сервера за допомогою `fetch` та `useEffect`.

Для отримання даних використовується API [JSONPlaceholder](https://jsonplaceholder.typicode.com/).

## Реалізовано

### ControlledForm

У контрольованій формі реалізовано:

* текстове поле для введення імені користувача;
* вибір ролі через `select`;
* чекбокс для підписки на email-сповіщення;
* збереження значень форми за допомогою `useState`;
* обробку відправки форми;
* відображення поточного стану форми в реальному часі.

### UncontrolledForm

У неконтрольованій формі реалізовано:

* введення ID користувача;
* отримання значення input через `useRef`;
* відправку форми без використання `useState` для контролю input;
* очищення поля після відправки.

### Запит до сервера

При завантаженні компонента `UncontrolledForm` автоматично виконується запит до API.

Користувач може ввести ID від 1 до 10 та завантажити інформацію про відповідного користувача.

Відображаються:

* ID;
* ім'я;
* email;
* місто;
* компанія.

Також передбачені різні стани:

* завантаження даних;
* успішне отримання даних;
* відсутність користувача.
